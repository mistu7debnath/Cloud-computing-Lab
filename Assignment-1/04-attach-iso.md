# Task 5 — Attach the ISO Image to the VM

## Objective
Attach the downloaded Ubuntu ISO image to the virtual machine.

## Steps
1. Opened Oracle VirtualBox.
2. Selected the `Ubuntu 26.04` virtual machine.
3. Opened **Settings**.
4. Navigated to **Storage**.
5. Selected the optical drive under the IDE controller.
6. Attached the downloaded Ubuntu ISO image:
   `ubuntu-26.04-desktop-amd64.iso`
